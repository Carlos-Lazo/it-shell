# Extracción de comandos posix

Web de referencia [List of POSIX commands]("https://wikipedia.org/wiki/List_of_POSIX_commands").


### Descripcion

Los items generan el contenido de un CSV con columnas: comando, descripción y categoria.

### Ejemplo:
- msgfmt,Create messages objects from messages object files,Misc
- mv,Move or rename files,File_system
- ne wgrp,Change to a new group,Misc
- ngettext,Retrieve text string from messages object with plural form,Misc
- nice,Invoke a utility with an altered nice value,Process_management
